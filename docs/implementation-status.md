站内提醒持久保存在所属对话，用户看到后才标记已读；网页关闭后后台可以继续处理。首版没有邮件或设备推送。个人对话不会在没有目标和授权时持续发起后台模型调用。

对话草稿保存于原聊天操作结果，确认后保留目标链接和规划进度；刷新可恢复，重复或并发确认只创建一个目标。新草稿会替换同一对话中尚未确认的旧草稿。确认目标仅启动候选计划生成，计划仍需单独确认，不自动修改共享每日学习时长。

## 复现方式

后端基础测试：

```bash
cd backend
uv sync --frozen
uv run ruff check app tests
uv run pytest -q
```

完整数据库/Temporal 测试需要本地进程可访问的独立测试连接：设置 `APP_TEST_DATABASE_URL`、`TEMPORAL_TEST_ADDRESS`、`TEMPORAL_TEST_NAMESPACE` 后运行同一命令。不设置时 PostgreSQL 和 Temporal 专属测试会跳过。数据库 fixture 为每个用例创建随机隔离 schema，结束时仅清理该 schema。不能将跳过测试的结果称为完整通过。

```bash
cd frontend
npm ci
npm run typecheck
npm run lint
npm test -- --run
npm run build
```

```bash
python3 scripts/test_configure.py -q
./scripts/smoke-test.sh
# 仅在配置真实模型并接受供应商费用后手动执行：
./scripts/smoke-test.sh --live-model
```

`--live-model` 最多 4 次请求、每次 512 输出 Token、总计 6000 Token；仅验证当前别名的一次工具调用与结构化中文输出，不能替代完整质量/费用验收。详细配置与部署步骤见 [部署说明](deployment.md)。
